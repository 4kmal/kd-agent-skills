# Bundled example: "The KD Brief: Agent Skills"

`storyboard.json` holds a finished six-scene report about agent skills; `plan.js` and `words.js` match its recorded voice, so `node snap.mjs 1 5 12 20 30 40` previews it straight away. The three cut-out photos are not redistributed here; fetch them first:

```bash
node research/capture.mjs anatomy=https://skills.wheresryan.sh/anatomy supabase=https://supabase.com/docs/guides/ai-tools/ai-skills
# img/kd.jpg: any 16:9 still, e.g. a frame of a KD Tech Daily episode
```

Then follow SKILL.md from step 4 (record, plan, word times) before rendering with sound. The published video is at https://wiki.krackeddevs.com/agent-skills.
